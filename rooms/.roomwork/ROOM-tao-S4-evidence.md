# 桃桃房 S4 · 五件证据 —— 素材设计稿

「镜头外那半」的全部内容。现状一件都没有,这五件是这间房真正想说的话。

设计前提:**交互是角色档案的出口**(阿云房的经验)。每件都可点击,台词必须是桃桃的口吻 —— 傲娇、句尾带「哼」、**想说真话会拐成刺**。台词写"她会怎么解释这件东西",而她的解释永远是遮掩,遮掩本身就是内容。

分层遵循 METHOD T1:每件 3–7 层,**少而精 + 每个都分层 > 多而平**。

---

## E1 · 准确率折线图墙

`x60 y480 · 420×260` · `scope: character` · `zLayer: above`(墙面件)

她的要强和不肯问人,全在这一面墙上。

| 层 | 内容 |
|---|---|
| ① | 四张纸,边缘不齐,用胶带斜着贴 —— 不是打印的,是手撕的作业本纸 |
| ② | 淡蓝格线(作业本原有的),不是坐标纸 |
| ③ | 折线本体:红笔,**画得很用力**,有几处折返压过头 |
| ④ | 纵轴刻度歪斜,间距不均 —— 尺子没对齐,肉眼估的 |
| ⑤ | 每个数据点旁边一个小字日期,字很小很挤 |
| ⑥ | 最新一段折线**向上**,末端画了个箭头 |
| ⑦ | 右下角一处涂改,底下透出被划掉的旧数字 |

**关键的一笔**:折线是红笔、用力、有涂改。**打印出来的图表说的是"专业",手画且涂改的图表说的是"在乎"。**

**台词**:「看什么看，不会用表格软件怎么了，哼」

## E2 · 奶茶空杯架

`x420 y860 · 120×160` · `scope: character` · `zLayer: low`

第一笔打赏九块九买的那杯,洗干净留到现在。后面的陆续摆成一排。

| 层 | 内容 |
|---|---|
| ① | 三层小木架,自己钉的,层板不平 |
| ② | 空杯 5–6 只,**大小不一**(不同店),都洗得发亮 |
| ③ | 最下层最左那只**单独放**,和其他隔开一个身位 |
| ④ | 那只杯身上有褪色的手写标签,字迹已经看不清 |
| ⑤ | 杯口一律朝上,排列整齐 —— 藏东西的地方也是整齐的 |
| ⑥ | 架子边缘一小片水渍印 |

**关键的一笔**:**第一只单独隔开**。不用任何文字说明,位置本身就是纪念。

**台词**:「攒着……攒着卖钱不行吗？第一只？第一只怎么了」

## E3 · 手账 · 抄满观众 ID

`x80 y820 · 300×200`(桌面件,与书桌合置)· `scope: character` · `zLayer: low`

有人在弹幕说今天很难过,她回「关我什么事」,然后把那条抄下来了。

| 层 | 内容 |
|---|---|
| ① | 摊开的本子,左右两页 |
| ② | 密密麻麻的短行 —— 不是句子,是**一行一个 ID** |
| ③ | 有些 ID 后面跟一小段字,更小更挤 |
| ④ | 几行被红笔圈起来 |
| ⑤ | 页边贴了三四张彩色小标签,分类用的 |
| ⑥ | 旁边一支笔,笔帽没盖 |
| ⑦ | 本子下面压着更多本,书脊可见 —— **不止这一本** |

**关键的一笔**:**下面压着更多本**。一本是习惯,一摞是执念。

**台词**:「记一下而已，又不是……又不是记得住每一个」

## E4 · 练字纸篓

`x100 y1120 · 140×140` · `scope: generic`(纸篓通用,其他房可复用)· `zLayer: low`

她的招牌字很丑。有人说难看,她说「这叫风格」,然后半夜偷偷练。

| 层 | 内容 |
|---|---|
| ① | 竹编纸篓,编纹交错 |
| ② | 揉皱的纸团,**堆到满出来** |
| ③ | 最上面一团半展开,能看见毛笔字的一角 |
| ④ | 篓外地上还有两三团 —— 扔偏了没捡 |
| ⑤ | 纸团有新有旧:上层白,底层泛黄 —— **练了很久了** |

**关键的一笔**:**纸团有新旧分层**。一晚上的挫败和长年的坚持,是两回事。

**台词**:「……谁半夜练字了。这是废纸，收着卖的」

## E5 · 师父的香位

`x300 y1120 · 160×200` · `scope: character` · `zLayer: sort`

嘴上说「来还愿的」,其实是道歉——她把师父守了一辈子的规矩,讲成了段子。

| 层 | 内容 |
|---|---|
| ① | 小小的木龛,朴素,没有装饰 |
| ② | 一块没有字的牌位 —— **她不敢写** |
| ③ | 香炉,三炷香,**长短不一**(不是同时点的) |
| ④ | 一枝干桃花,和窗边那枝同源 |
| ⑤ | 龛前一小块地面被跪得发亮 |
| ⑥ | 供着一杯奶茶 —— 与 E2 同款 |
| ⑦ | 极轻的一缕香烟(`fx`,幅度参照阿云房香炉) |

**关键的一笔**:**牌位无字 + 供一杯奶茶**。无字是她不敢承认自己在道歉;奶茶是她唯一能给的、属于她自己的东西。

**台词**:「还愿。就是还愿。……您别多想」

## 与镜头内那半的呼应

这五件不是孤立的,每件在舞台那半都有一个对位:

| 镜头外(证据) | 镜头内(舞台) | 说的是同一件事 |
|---|---|---|
| E1 手画折线图 | 应援灯牌「桃」 | 数据 vs 排面 |
| E2 洗净的第一只空杯 | 直播台的打赏特效 | 九块九 vs 流水 |
| E3 抄满 ID 的手账 | 拍立得照片串 | 记住别人 vs 被人记住 |
| E4 练字废纸 | 手写招牌(字很丑) | 私下练 vs 公开挂 |
| E5 无字牌位 | 奇门局桌 | 违背师门 vs 靠师门吃饭 |

**E4 ↔ 招牌 是最直接的一对**:招牌就挂在镜头里,丑字人人看得见;纸篓在镜头外,没人知道她练。屏风一拉,两边同时存在却互不相见 —— 这就是这间房。

# 新房接线清单 —— 引擎给了什么 · 什么必须自己长

**这不是骨架模板,不要照抄。** 2026-07-22 实建一间房验证得来(建完即删)。

照抄骨架错在哪:布局拓扑照抄 = 36 间同一套骨架换皮(铁律禁止);行为表照抄 = 36 个人
做一模一样的事;连 loop 的分叉都是从「这个人怎么动」推出来的 —— 婆婆骑扫帚所以有
`airborne`,丹增跳梅花桩所以有 `stepHop`,阿云有猫所以多一条宠物支线。
**抄来的结构会替你把这些问题跳过去,而那些正是这间房要回答的。**

同一天删掉的 36 间占位骨架(统一灰白墙 + 空 items + 配好的按钮文案)也是同一个病。

---

## 一、硬约定 —— 必须照做,不然门禁找不到这间房

`tools/rooms.js` 靠命名发现房间。**遵守了,十道门禁自动认得新房,一个工具都不用改。**

| 东西 | 名字 |
|---|---|
| 房间对象 | `window.<NAME>_ROOM`,且带 `plan` 数组 |
| 画布 | `<name>Canvas` |
| 主按钮 | `<name>CastBtn` |
| 角色 id | `<name>` |

另外两条不守就出静默错:
- **`defineActor` 写在引擎侧素材库脚本**,不能写房间脚本 —— 房间脚本先于引擎加载,写那里会**静默注册不上**
- **一间房一个 `<script>`** —— 两间共用一段,`hardcodelint` 按 canvas 切的区间会串房

## 二、引擎给了什么 —— 这些照用,别自己写第二套

**同一职能出现第二份实现,两份一定会漂**(命中排序漂了几个月,症状是「看得见的点不到」)。

| 要做的事 | 调什么 |
|---|---|
| 渲染整间房 | `renderRoom(g, room, t, ents)` |
| 摆角色 / 摆家具 | `placeActor(id, footX, footY, pose, flip, opt)` · `placeAsset` |
| 选下一个行为 | `pickAct(acts, cur, {filter})` |
| 走过去 | `startWalkTo` → `stepWalk(self, speed)`(轴优先,走 L 形) |
| 飞过去 | `stepFly`(斜线,不寻路) |
| 在落点间跳 | `stepHop(self, pts, t, {period,height})` → 给 `lift` / `phase` |
| 站姿微动 | `idlePose(self, pose, id)`(眨眼/呼吸) |
| 踱步 | `stepPace` |
| 朝向 → 姿态 | `faceOf(dx, dy)` · `walkPose` |
| 表演态 | `wirePerform(room)` + `stepPerform(room, st, t, {startWalk, pick})` |
| 房间状态 | `roomState(room, {...})`,家具用 `variant(state, t)` 读 |
| 交互 | `attachRoomInteraction(cv, room, {})` + `drawInteraction(g, room, cv, t)` ← **漏一句所有交互都是死的** |
| 气泡 / 表情 | `drawSay` · `drawEmote` |
| 寻路 | `roomGrid`(从 `foot` 自动烧格)+ `gridPath` |
| 做旧 | 素材标 `patina: true`(蒙尘)/ `'wood'`(木头氧化开裂) |

**姿态**:四向与走路帧二由 `codex` 提供(40 个角色齐全);**站姿 codex 只填空不覆盖** ——
房间画了就用房间的(婆婆的四向图骑着扫帚,她停下来搅锅时不该还扛着)。
`castlint` 会在开工前告诉你这个角色缺哪几个姿态。

**表演加速**:`perform.actor.speed` 会被合并进行为对象,loop 里写 `stepWalk(st, st.act.speed || 平时值)`
就自动生效 —— 玩家点了按钮还要等他慢慢晃过去,是最直接的挫败感。

## 三、什么必须自己长 —— 一条都不许抄

| | 为什么 |
|---|---|
| **布局拓扑** | 铁律:不许复用布局骨架,撞车即回炉。36 间同一套骨架换皮 = 36 间都不成立 |
| **素材** | 四房实测自画率 **100/100/100/91%**。遮住其余部分单看一件,能读出是谁的屋子 → 必须自画。借的只能是扫帚挂钩碗碟这类 |
| **墙色 · 地板 · 光** | 按这个人的气质定。删掉的占位骨架给 36 间配了同一个 `#c9c4bc` 灰白墙,那正是要避免的 |
| **姿态** | 正面与功能姿态(坐卧读凝视)房间自画;每个人怎么坐、怎么读都不一样 |
| **行为表** | 他在这间房里真正做的事,从 S2 的三条功能诉求来。抄来的行为表 = 36 个人做一样的事 |
| **台词** | 每一句都要是**这个人**说的话。要么搞笑、要么哲理、要么讽刺、要么感慨 |
| **loop 的分叉** | 飞(`airborne`)/ 跳(`stepHop`)/ 有状态家具(`roomState`)/ 睡床(`sleepAt`+`attach`)—— 装哪几个,取决于这个人怎么活动 |

## 四、建完先跑这几道,别等做完

```
castlint <file> <name>      # 开工【前】就该跑:这人够不够开房
verify                       # 应报「发现房间 N 间」,含新房
poselint / walklint          # 四向齐、不滑行(名字齐≠像素齐)
assetlint                    # 逐房布局 · 通道 · 可达无孤岛
pathlint                     # 锚点不在家具内、路径不穿家具
roomaudit                    # 姿态可用 · 表演有视觉 · 逐件点得到 · foot 对得上
regress save                 # 确认视觉无误【之后】再收录基准
```

实建那次,`poselint` 当场抓到缺四向站姿、`roomaudit` 当场抓到「表演时画面没有任何变化」——
**门禁在新房上是真会说话的。**

# 白鹭 · 观里的女冠 —— S1 角色档案

`castlint ④` 的八问。机器判不了,逐条答;答不出就不许进 S2。

**B9 已有**:紫微斗数 · 终南山 · 冷淡极准洁癖 · 缺「热」·
背景「她排的盘密不透风,从不多说一个字」· 关键经历「有人求她改命,她说『命盘我只念,不改』,转身闭关三年」·
说话风格「短、冷、精确到分秒」。

---

## 1. 来处给的那一句话

师父下山前留的:**「你念得准。可你念的时候,眼里没有人。」**

她带着这句下山,而且**认这句是对的** —— 所以她后来的每一步都在证明它:
准到不能再准,人也离得不能再远。

## 2. 证明过自己的那次

**山洪之夜**。阿云午睡醒来随手起课说「今晚有水」,没人信那个总在睡觉的小道士 ——
**是她排的盘把这句话变成了可信的**,然后沈砚才挨家敲的门。全村得救。

关系表里那条「同修道门,一个极准一个极懒,观里至今拿他俩当反例」就是从这儿来的。
她做成的事从不署自己的名,那次也一样。

## 3. 失败的方式 ★ 不许与已用重复

**「看得最清楚的人,什么都没做。」**

| 已用 | |
|---|---|
| 阿云 | 别人都信了他自己不信 |
| 桃桃 | 做对了没人看见 |
| 婆婆 | 给了所有人没给自己 |
| 丹增 | 找到了却不被承认 |
| 沈砚 | 做对了,而做对本身就是伤害 |
| **白鹭** | **看得最清楚,却什么都没做** |

前五种都是**做了**之后的败法,她是**不做**。「命盘我只念,不改」——
她把"不介入"当成了操守,而那正是她缺的那个「热」。

## 4. 兴趣能落成哪些物件 ★ 要撑得起房间一块区域

**她给多肉排盘。**

一屋子多肉,每一盆插着一块小命盘牌,写着入盆的年月日时(精确到分)、当年流年、宜忌。
浇水记录本上是「卯时三刻 · 12ml」这样的字。她认真极了。

| 落成物件 | |
|---|---|
| 多肉架(三层,几十盆) | 区域主体 |
| 每盆插着的命盘小牌 | 这一区的语言 |
| 浇水记录册(精确到分) | 她的"准"用在这儿 |
| 铜镊子 · 小喷壶 · 分装的土与石子 | 洁癖的手感 |
| 《盆植流年》手抄本 | 她自己编的,只有一本 |
| 一盆枯死的,牌子还插着 | ★ 这一盆是钩子 |

**够撑起一整面墙** —— 对照:桃桃直播区占半间房、丹增鼓组占整个右侧。

## 5. 分界线的物理形态 ★ 不许与已用重复

**「半蒙 · 露出真身」** —— 凡与**人**有关的,搭一块白布【但露出真身】——一眼认得出是椅子/琴/镜,却都搭着布;凡与**盘/植物**有关的,全然敞开、擦得发亮。

| 蒙着白布的 | 露着擦亮的 |
|---|---|
| 客位的座 | 星盘与式盘 |
| 镜子 | 多肉架整面 |
| 一张合影 | 排盘用的长案 |
| 一封没拆的信 | 笔、尺、镇纸,全部对齐 |

| 已用 | |
|---|---|
| 阿云 | 一件 vs 全屋 |
| 桃桃 | 左右两半(空间切分) |
| 婆婆 | 成对物件同框 |
| 丹增 | 保养状态(蒙尘↔锃亮) |
| 沈砚 | 层积(每处平面都压着更旧的一层) |
| **白鹭** | **半蒙 · 露出真身(与人有关的全盖着)** |

玩家扫一眼就能读出来:**这屋里有一半东西不给看**。

## 6. 笑点即痛点

**她给一盆多肉排流年,写「今年不宜移栽」,还真就不移。**

笑点在这儿,痛点也在这儿 —— 她愿意为一盆植物算到分秒、并且照着做,
却对求她改命的人说「我只念,不改」。**同一件事的两面。**

## 7. 一道裂缝 —— 核心物件与 sayDeep

**核心物件:蒙着白布的那把客座。**

| 追问 | 她说 |
|---|---|
| 一 | 「那是客位」 |
| 二 | 「……很久没人坐了」 |
| 三 | 「有人坐过。他求我改命,我说我只念不改。第二年他就没了」 |

「被逼着才说」本身就是那个缺的形状 —— 她的话短、冷、精确,唯独这三句一句比一句长。

## 8. 反差落在同一个伤口上

对植物极热、对人极冷,**不是两种性格,是同一件事**:

> 她只对**不会因为她的话而死**的东西上心。

多肉不会来求她改命。所以她敢把「热」全给它们。

## 布局意图

三个功能区**不割裂成三块** —— 分界线是「层积」不是空间切分(那是桃桃用过的)。
所以:**每个区各自都有「表层 + 压在下面的」**,层积靠重复出现成为语言。

```
        ┌──────────────────────────────────────┐
 墙 440 │ 格窗      字幅      ▓▓▓ 推 号 墙 ▓▓▓ │  ← 唯一的天光在左,推算图占右侧一整片
        ├──────────────────────────────────────┤
        │           ·                推号桌     │  ← 上部:两张桌隔着中间的空
   900  │   测字案 ▭                  ▭        │
        │     ○客凳                            │
  1200  │              (留白 · 走道)   [开奖屏] │  ← 全屋唯一主动发光的东西
        │                            刮刮乐堆   │
  1500  │  纸架 ▤                              │
        │   油灯                    废纸篓      │  ← 左下读书角,与右上推号区对角
  1900  │        ▨ 卷子箱(压在最底)             │
        │                                      │
  2300  │   门垫        地上的纸屑              │  ← 底部锚定,不让画面头重脚空
        └──────────────────────────────────────┘
```

**留白**:中部 y1250–1450 横贯的走道 · 左上 y500–850 一片空墙下的空地。
**底部**:门垫 + 纸屑 + 卷子箱压住下三分之一(阿云房是范本 —— 底部空着就头重脚空)。
**中心**:不放大件。这间房没有「中心大件」,因为立意是层积 —— **焦点是重复,不是一件**。

## 校验

**主角房不能用 `planlint.py`**(它只解析村民房的 `FULLROOMS` 结构,会打印「0/36 间违规」的假绿)。
用本目录的 `plan-shenyan.js` 自校:重叠 · 越界 · 通道 ≥40px · 从门口 BFS 全可达无孤岛。

S5 画完素材后**回头**再跑一次 `assetlint`(真 `foot`)+ `roomaudit D`(foot vs 实体像素)。

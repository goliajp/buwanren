## 框架的新发现:四人的「缺」是咬合的

B10 关系网里两条现成的线,证明四主角框架比原先写的更紧:

| 关系 | B10 原文 | 说明 |
|---|---|---|
| 婆婆 → 桃桃 | 她教她怎么在镜头前笑,桃桃学了,**但只在她面前笑** | 婆婆缺亲人 → 教出一个只对她笑的女孩;桃桃缺直率 → 真心的笑只给一个人。**两人的缺互相填补** |
| 丹增 → 阿云 | 一个练拳一个躺着,**居然成了搭子** | 缺静 × 缺勤,动静相济 |

**这条要写进四主角框架**:「缺一个字」不只是每人的解释项,四个字之间还构成一张互补网 —— 谁能填谁的缺,决定了谁和谁走得近。这是关系网不用另行设计、自己就长出来的原因。

## POPO · 婆婆 · 占卜的老太太

`塔罗 · 水晶球 · 黑森林 · 缺「亲人」· 珍 · 已入住`

| 项 | 内容 |
|---|---|
| 名 · 号 | 婆婆(没人知道她本名。她说「叫婆婆就很好听呀」) |
| 流派 | 塔罗 · 水晶球 · 读牌不读命,只说「我看见什么」 |
| 出身 | 黑森林 |
| 性格 | 慈祥 · 神秘 · 爱操心 |
| 口头禅 | 尾音上扬带「哦」「呀」。动不动塞糖 |
| 谋生 | 不收钱,收东西 —— 一颗糖、一句话、一次帮忙都算 |
| **缺「亲人」** | 她一个人住了太久,**把每一只路过的动物都留了下来**。屋里现在有多少只她自己也数不清 |
| 现代兴趣 ① | **给每只动物织毛衣**。织的是人的款式改小的 —— 她照着给孩子织的图样在织 |
| 现代兴趣 ② | **用智能机发六十秒语音条**,全村都收到过。她不会打字,也不肯学 |
| 不能碰 | 不给自己算。她算过**一次**,牌摊开之后再没算过第二次 —— 结果她没跟任何人说 |
| 真正的秘密 | 她记得全村每个人的生日,提前一天开始准备。没有人告诉过她这些日子 |

### 编年史

| 时 | 事 |
|---|---|
| 早年 | 黑森林。她说那边「树太高了，天很小哦」 |
| 某年 | 一个人搬到不完人村。为什么一个人,她从没说过,也没人敢问 |
| 第一只 | 一只受伤的猫躲进她门廊。她说「你要住下也可以呀」—— 从此再没拒绝过任何一只 |
| 说不清多久 | **「婆婆的团圆」** —— 她替全村算过团圆,唯独没算自己 |
| 那一次 | 她给自己摊了一次牌。之后把那副牌收进抽屉,换了新的一副 |
| 后来 | 小邮送错过一枚御守到她门口。**婆婆说「送对了」**,挂在门上到现在 |
| 后来 | 她教桃桃怎么在镜头前笑。桃桃学会了,**但只在她面前笑** |
| 后来 | 赛博把她的牌阵写成了算法。婆婆说「电子的也是牌灵哦」 |
| 今 | 每天煮的饭都比一个人多。剩下的分给动物 |

**设计要点**:笑点即痛点 —— **她给所有人当亲人,自己没有亲人**。房间的分界线是「给别人的 ↔ 给自己的」:塞给别人的糖罐永远是满的,她自己的碗只有一只;给动物织的毛衣堆成山,她自己的披肩磨破了没换。**那副收进抽屉的旧牌是这间房的核心物件** —— 抽屉关着,但玩家能点开。

## TENZ · 丹增 · 下山的武僧

`藏历密算 · 雪山寺 · 缺「静」· 珍 · 已入住`

| 项 | 内容 |
|---|---|
| 名 · 号 | 丹增。村里小孩叫他「鼓和尚」,他不纠正 |
| 流派 | 藏历密算 · 算日子不算人 · 断吉日最准 |
| 出身 | 雪山寺 |
| 性格 | 耿直 · 热血 · 话少 |
| 体貌 | 高大。手上全是茧,一半是练拳磨的,一半是打鼓磨的 |
| 口头禅 | 短句。爱说「嘿哈」。认真时一句顶万句 |
| **缺「静」** | 寺里说他心不静,让他下山「**练完一百零八式再回来**」 |
| 现代兴趣 | **摇滚鼓**。他在山下听见了第一段摇滚,**从此鼓比经好听** |
| 谋生 | 替人选日子。红白喜事都找他 |
| 不能碰 | 别问他一百零八式练到第几式了 |
| **真正的转折** | 打鼓的时候他心是静的。**寺里让他找的东西,他找到了 —— 但不在寺里,而且寺里不会认** |

### 编年史

| 时 | 事 |
|---|---|
| 幼年 | 送进雪山寺。他不记得是谁送的 |
| 少年 | 拳打得最好,经念得最差。师兄说他「打拳像打架，不像修行」 |
| 那一年 | 寺里让他下山:「练完一百零八式再回来」。他以为这是惩罚 |
| 下山那年 | 在山里迷了路。**是婆婆指的路** |
| 山下第一晚 | 路过一间酒吧,听见了第一段摇滚。他在门口站到打烊 |
| 之后 | 攒钱买了第一面鼓。练拳的节奏开始越来越像鼓点 |
| 某天 | 他发现打鼓的时候,心是静的。**这件事他没告诉任何人** |
| 半年前 | **广场之争** —— 他要排练,桃桃要直播,各占半边。阿弥趁乱抄了桃桃的局;两人因为一起骂阿弥,勉强算熟了 |
| 后来 | 和阿云成了搭子。一个练拳一个躺着 |
| 今 | 一百零八式还差最后几式。他不练了 —— 也没回去 |

**设计要点**:笑点即痛点 —— **他被赶下山去找「静」,找到了,却是用寺里不会承认的方式**。房间的分界线是「经堂 ↔ 鼓」:经堂那半积着灰,鼓那半天天擦。**一百零八式的记数牌是核心物件**,停在某个数字上很久没动了。他不练不是因为放弃,是因为他已经知道答案,只是不敢回去说。

## 四人对照(框架填满后的验证)

| | 缺 | 来处给的一句话 | 证明过自己的那次 | 失败的方式 | 现代兴趣 | 房间的分界线 |
|---|---|---|---|---|---|---|
| 阿云 | 勤 | 你缺的不是本事,是起床 | 十六岁断山洪 | 别人都信了,**他自己不信** | 二次元 | 式盘桌 ↔ 其余 |
| 桃桃 | 直率 | 奇门不外传 | 十八岁断雨 | 做对了,**没人看见** | 直播与数据 | 镜头内 ↔ 镜头外 |
| 婆婆 | 亲人 | (无师门 —— 没人给过她那句话) | 替全村算团圆 | 给了所有人,**没给自己** | 织毛衣 · 语音条 | 给别人的 ↔ 给自己的 |
| 丹增 | 静 | 练完一百零八式再回来 | 山下听见第一段摇滚 | 找到了,**却是不被承认的方式** | 摇滚鼓 | 经堂 ↔ 鼓 |

四种败法互不重复,框架成立。婆婆那一格的空白(没有师门、没人给她那句话)**本身就是她的缺**,不是漏填。

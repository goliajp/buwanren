# 项目规则 · buwanren（卜万人）

## 中文标点必须全角 ★ 反复犯的错

**任何中文内容里的标点一律用全角**,没有例外。这条被用户明确指出过是「你永远都在犯的错」。

| 半角(错) | 全角(对) | |
|---|---|---|
| `,` | `，` | 逗号 |
| `?` | `？` | 问号 |
| `!` | `！` | 叹号 |
| `;` | `；` | 分号 |
| `:` | `：` | 冒号 |
| `...` | `……` | 省略号(中文用六点占两格) |
| `--` | `——` | 破折号(占两格) |
| `()` | `（）` | 括号 |

引号用 `「」`(单层)与 `『』`(内层),不用 `""`。

## 非正式文本结尾不加句号 ★

台词、气泡、短句、列表项、标题这类**非正式文本，结尾不写句号**。句号会让一句话显得生硬、像书面公文，而角色说话不是在念稿。

| 错 | 对 |
|---|---|
| 「看什么看，不会用表格软件怎么了，哼。」 | 「看什么看，不会用表格软件怎么了，哼」 |
| 「还愿。就是还愿。……您别多想。」 | 「还愿。就是还愿。……您别多想」 |

**只去掉结尾那个**——句中用于断句的句号照常保留（见上面第二例）。问号、叹号、省略号表达语气，结尾该留就留。

**适用**：角色台词、气泡文案、界面短句、表格单元格、列表项、标题
**不适用**：正式文档的正文段落、说明性长句

### 适用范围

**必须全角**:
- 角色台词(`say:` 字段、气泡文案、念白)
- 面向用户的界面文案
- 中文设计文档 / 档案 / 编年史
- 中文注释里的自然语句

**保持半角**:
- 代码本身(标识符、字符串键、JSON)
- commit message(英文写作)
- 面向公开仓库的英文文档
- URL、版本号、数字表达式、文件路径
